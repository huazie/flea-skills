# 一次性登录助手（推荐，替代手动导出 Cookie）

从 v2.0.0 起，默认采用「原生持久化 profile 模式」：不再需要把登录态导出成 cookies.json，
而是让签到脚本复用**系统 Chrome 的持久化登录态**——和「你正常用 Chrome 一直登录着 51CTO」是同一机制，
登录态长期有效，无需每日续期。

## 使用步骤

1. 在**有图形界面的终端**（能弹出浏览器窗口）进入技能目录（即含 SKILL.md 的目录）：
   ```powershell
   cd <技能目录>
   ```
2. 运行登录助手：
   ```powershell
   node scripts/login.mjs
   ```
3. 自动弹出的 Chrome 窗口中登录 51CTO（输入账号密码、过验证码）。
4. 登录成功后：
   - 助手检测到登录态会**自动**关闭窗口，登录态已存入 `chrome-profile/`；或
   - 若未自动触发，登录完成后在终端窗口按 **Enter** 手动确认。
5. 看到「已确认登录态，profile 已持久化」即完成。此后每日签到无需任何手动操作。

## 续期与重新登录

- 登录态由 Chrome 自身持久化保管（App-Bound 加密），像正常 Chrome 一样长期保留；
  只有当 51CTO 服务端让会话失效、脚本返回 `COOKIE_EXPIRED` 时，才需要重新运行一次 `node login.mjs` 刷新。
- 与旧版（导出 cookies.json）相比，少了「导出态过期 → 反复续期失败」这一环。

## 注意

- 登录助手会启动**有头** Chrome，需要本机桌面环境；服务器/无图形界面环境无法使用，需在本机执行。
- `chrome-profile/` 含有登录凭证，**切勿上传到任何仓库或发给他人**（已被 .gitignore 忽略）。
- 仅用于本人账号的每日签到，勿用于批量/他人账号。
- 如需退回旧的 cookies.json 模式（不推荐），设置环境变量 `USE_COOKIES=1` 运行 `login.mjs` 与 `checkin.mjs`。
